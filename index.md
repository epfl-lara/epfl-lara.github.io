# LARA 

**Helping construct software that does what we expect.**

[LARA](https://lara.epfl.ch/w/) is a research group led by [Viktor Kunčak](http://lara.epfl.ch/~kuncak/). We develop precise automated reasoning techniques: tools, algorithms and languages. The goal of these techniques to help construction of verified computer systems. We develop several open-source projects. 
  * [Stainless](https://github.com/epfl-lara/stainless) is tool for constructing formally-verified software that is guaranteed to meet specifications for all inputs (see [the ASPLOS tutorial](https://epfl-lara.github.io/asplos2022tutorial/)). The primary input format to Stainless is a subset of [Scala](https://www.scala-lang.org/)
  * [Bolts](https://github.com/epfl-lara/bolts) illustrates several case studies carried out using Stainless
  * [LISA](https://github.com/epfl-lara/lisa) is a project to develop proof assistant based on set theory
  * [Scallion](https://github.com/epfl-lara/scallion) is a library for provably correct parsing and pretty printing
